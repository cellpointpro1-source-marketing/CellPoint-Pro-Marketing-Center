# 2. HOSTING / DEPLOYMENT ARCHITECTURE

The application will be developed in **Replit**.

Source code will be maintained in **GitHub**.

The frontend will eventually be deployed through **Netlify**.

Design the application so that the frontend, backend/API, database, authentication, scheduled jobs, and external integrations can be separated when necessary.

Do NOT tightly couple the application to Replit hosting.

Do NOT assume Netlify should host every backend process.

The architecture should allow:

**Replit → GitHub → Netlify**

while allowing backend services and databases to be hosted independently.

# 10. SOCIAL API RULES

This is extremely important.

Never scrape Facebook, Instagram, TikTok, YouTube, or Google websites.

Never ask users for social-media passwords.

Use official OAuth/API integrations.

Use official APIs and permissions.

Respect:

* API permissions
* Rate limits
* Platform policies
* App-review requirements
* Business verification requirements

If a platform does not allow a specific feature through its API, do not attempt to bypass the restriction.

* Disable that feature
* Explain why
* Provide an appropriate alternative
